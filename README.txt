FROSTCLOUD WEBSITE
==================
Files:
  index.html        the page
  css/style.css     main styles
  css/responsive.css  phone/tablet styles
  js/config.js      YOUR SETTINGS (Discord invite, ticket link, order text)  <-- edit this
  js/main.js        interactions (menu, panel demo, plugin filter, etc.)
  assets/           logo, favicon, hero background

IMPORTANT - change in js/config.js:
  DISCORD_INVITE  = your server invite
  TICKET_URL      = link of your ticket channel (right-click channel > Copy Link)

Prices/plans are in index.html (search for "plan-grid").
Deploy: upload to GitHub (keep the folder structure) and import in Vercel, framework "Other".
